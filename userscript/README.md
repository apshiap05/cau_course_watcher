# Tampermonkey 用户脚本

文件：[`cau-course-watcher.user.js`](./cau-course-watcher.user.js)

## 安装

1. 从浏览器官方扩展商店安装 Tampermonkey。
2. 打开 [Raw 脚本地址](https://raw.githubusercontent.com/apshiap05/CAU-/main/userscript/cau-course-watcher.user.js)。如果 Tampermonkey 显示安装页，检查脚本名称和匹配域名后安装。
3. 如果浏览器只显示源码，就复制全部内容，在 Tampermonkey 中选择“添加新脚本”，替换示例内容并保存。
4. 登录中国农业大学教务系统，进入选课页面并刷新。
5. 页面右侧应显示“选课余量监控助手 v1.4.0”。脚本匹配 `/jsxsd/xsxk` 本身及其下任意路径，不依赖固定选课批次参数。

更新时可以重新打开 Raw 地址；脚本元数据也包含同一地址作为 `@updateURL` 和 `@downloadURL`。

## 使用

1. 在面板顶部选择“正常模式”或“多选模式”。
2. 正常模式只显示并填写第一门课程，不显示增加或删除按钮；多选模式使用待选课程标题栏右侧的“＋ 添加课程”和课程块内的“−”维护 1–4 个待选课程块。
3. 每门课程可独立填写课程名称、教师、课程编号、课序号、校区、时间关键词、最低余量和多班选择策略。
4. 全部课程共用课程块下方的刷新间隔、随机抖动和最大查询次数。多选模式会按课程块顺序交替输入课程名并点击查询。
5. 点击“仅查询一次”或“仅轮询一轮”核对匹配结果。这些按钮不会自动选课。
6. 确认“自动点击本次选课流程中的所有‘确定’弹窗”已勾选。
7. 勾选“本次授权”，然后点击“开始监控”，在配置摘要弹窗中核对并确认。授权状态不会保存，刷新页面后必须重新勾选。
8. 随时点击“立即停止”或按 `Esc` 紧急停止。

配置变更会在鼠标离开面板时自动保存并显示 3 秒提示。面板顶部显示五项页面健康状态；每门课程拥有独立运行状态。多选模式默认任意一门成功后停止，也可改为继续监控直到全部课程选中。

从 v1.2.0 更新到 v1.3.0 后，原单课程配置会自动迁移到正常模式的第一门课程，原有设置不会被丢弃。

脚本会调用教务页面自己的查询和 `xsxkFun(...)` 选课流程。选课调用期间出现的班级确认、课程组确认等连续 `confirm` 会依次自动返回“确定”，确认内容会显示在运行日志中；调用完成后立即恢复网页原始弹窗函数。

## 配置说明

| 配置 | 含义 |
| --- | --- |
| 课程名称 | 必填；“智能精确”允许 `羽毛球` 匹配 `羽毛球（1）`，输入自身带班号时会严格区分。 |
| 教师、课程编号、课序号、校区、时间 | 可选；同名多班时建议至少增加课序号或教师。 |
| 刷新间隔 | 默认 5 秒，最低 3 秒，并加入随机抖动。 |
| 最低余量 | 每门课程独立设置；剩余容量达到该数字时才准备选课，默认 1。 |
| 最多查询次数 | `0` 表示不限。 |
| 多班选择策略 | 每门课程独立设置；可以选择余量最多的班，或者结果页面中的第一班。 |
| 显示已满课程 | 便于观察目标课程的余量从 0 变为正数。 |
| 自动确认全部确定弹窗 | 仅在一次目标选课调用期间生效，包括班级确认和课程组确认。 |

## 自动暂停条件

- 页面要求验证码。
- 登录会话失效或跳回登录页面。
- 找不到关键输入框、查询按钮、课程表列或原生选课函数。
- 选课参数与当前课程行不一致。
- 教务系统返回时间冲突、限选、学分限制、未到选课时间等不可重试结果。
- 页面没有明确结果，并且在“选课结果查看及退选”中也无法验证成功。
- 连续网络或页面异常达到暂停阈值。

脚本不会保存账号、密码或 Cookie，不会识别验证码，也不会绕过学校的选课规则。最终选课结果请在教务系统中人工确认。
