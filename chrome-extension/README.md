# 中国农业大学选课余量监控助手（Chrome 扩展）

这是一个仅作用于 `https://newjw.cau.edu.cn` 指定选课页面的 Manifest V3 扩展。它不会保存账号、密码或 Cookie，只会在 Chrome 扩展存储中保存课程监控配置。

## 安装

1. 如果拿到的是 ZIP，先完整解压，不能直接选择 ZIP。
2. 在 Google Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本目录，也就是包含 `manifest.json` 的 `chrome-extension` 文件夹。
6. 安装或更新扩展后，刷新已经打开的教务选课页。

## 使用

1. 正常登录中国农业大学教务系统。
2. 点击扩展图标，再点“打开教务选课页面”；扩展会优先复用已经打开的 `https://newjw.cau.edu.cn/jsxsd/xsxk/` 下任意选课页面。
3. 页面右侧会出现“选课余量监控助手”配置面板。
4. 在面板顶部选择“正常模式”或“多选模式”。正常模式只显示并监控第一门课程，不显示增加或删除按钮；多选模式可通过待选课程标题栏右侧的“＋ 添加课程”和课程块内的“−”维护 1–4 个待选课程块。
5. 每个课程块都能填写课程名称、匹配方式、教师、课序号、课程编号、校区、时间关键词、最低余量和多班选择策略。
6. 多选模式按课程块顺序交替输入课程名并点击查询。全部课程共享位于课程块下方的刷新间隔、随机抖动和最大查询次数。
7. 建议保留“自动确认本次选课流程出现的所有‘确定’弹窗”勾选。它会处理首次“确认选择当前课程班级”以及随后出现的课程组确认等连续弹窗。
8. 可以先用“仅查询一次”或“仅轮询一轮”核对结果；这些按钮不会选课。
9. 勾选黄色框里的“本次授权”，再点击“开始监控”。核对弹出的完整配置摘要并确认后才会启动。该授权不会保存，刷新页面后必须重新勾选。
10. 可随时点击“立即停止”，或按 `Esc` 紧急停止。

配置字段变更后，鼠标离开面板会自动保存并显示 3 秒提示。顶部健康状态会检查页面识别、选课入口、课程表、原生函数和弹窗桥接；多选模式还能选择默认的“任意一门成功即停止”，或“继续直到全部课程选中”。

从旧版更新到 v1.3.0 及更高版本后，原单课程配置会自动迁移到正常模式的第一门课程。更新扩展文件后需要在 `chrome://extensions/` 点击该扩展的刷新按钮，并刷新教务页面。

## 自动确认的边界

- 只在发现余量并准备调用当前课程行的原生 `xsxkFun(...)` 时启用。
- 后台会校验请求来源、目标网址、参数格式，并核对课程表中确实存在参数完全一致的选课按钮。
- 在这一次选课调用期间，出现的所有 `confirm` 均返回“确定”，包括课程班级确认和课程组确认。
- 弹窗安静 2.5 秒或最多 15 秒后，无论成功或异常都会恢复网页原本的 `alert` 和 `confirm`。
- 验证码、登录失效、参数不一致、结果无法确认或连续异常会自动暂停并反馈原因。

## 注意

- 默认查询间隔为 5 秒，最低限制为 3 秒，并附加随机抖动及错误退避。请遵守学校规定，不要人为调高请求频率。
- 选课结果以学校教务系统为准。成功后请到“选课结果查看及退选”或课表中再次确认。
- Chrome 更新扩展代码后不会自动更新已打开页面中的内容脚本，需要刷新教务页面。
